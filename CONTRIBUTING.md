# Работа с изменениями

Спасибо за участие в проектах Orange Solutions.

## Задача

Опишите задачу в соответствующем репозитории: что нужно изменить, зачем и какой результат ожидается. Для ошибки добавьте шаги воспроизведения и ожидаемое поведение.

## Pull request

1. Прочитайте README и инструкции конкретного репозитория.
2. Подготовьте связанное изменение в отдельной ветке.
3. Выполните проверки, описанные в репозитории, и укажите результат в PR.
4. Кратко опишите изменение и добавьте ссылку на задачу, если она есть. Для изменения интерфейса приложите скриншот.

Не включайте в задачи, PR и примеры секреты, персональные данные и содержимое клиентских систем.

У каждого проекта могут быть дополнительные инструкции — следуйте им при работе с его кодом.
